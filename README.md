# r-help

<!-- badges: start -->

<!-- badges: end -->

This repository provides HTML help for previous versions of R.

The pages are extracted from the installed help in
[evercran](https://github.com/r-hub/evercran) Docker images. Existing
HTML is copied unchanged. R versions which store compiled help render it
with their own version of R. The build reads Evercran’s version lists
directly, so new releases do not have to be added here.

The [version index](https://hughjonesd.github.io/r-help/) links to a
simple index for every available R version.

For function metadata and comparisons across R versions, see the
[rcheology package](https://github.com/hughjonesd/rcheology) and its
[Shiny app](https://hughjonesd.shinyapps.io/rcheology/).

The site is built in GitHub Actions. Generated HTML is not committed to
this repository.

Some very old help may not render correctly.
