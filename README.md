# r-help

<!-- badges: start -->

<!-- badges: end -->

This repository provides HTML help for previous versions of R.

The pages are extracted from the installed help in
[evercran](https://github.com/r-hub/evercran) Docker images. Existing
HTML is copied unchanged. Compiled help is rendered into HTML by the 
historical version of R. 

The [version index](https://hughjonesd.github.io/r-help/) links to a
simple index for every available R version.

The site is built in GitHub Actions. Generated HTML is not committed to
this repository.

Some very old help may not render correctly.
